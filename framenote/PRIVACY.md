# 帧记隐私说明

更新日期：2026-10-27

帧记（FrameNote）是一个本地优先的浏览器扩展，没有自有服务器、没有账号体系、没有遥测或广告 SDK。

## 我们处理哪些数据

- **笔记、截图、对话、设置**：保存在浏览器扩展的 `chrome.storage.local` 中，仅在你本机可读。
- **API Key**：保存在本机 `chrome.storage.local`，仅用于向你配置的 AI 服务发起请求。
- **视频页面内容**：当你主动点击「AI 笔记 / 速览 / 出题 / 导图 / 助手 / 识字 / AI 转写」等按钮，或开启「自动识别音频」时，扩展会将必要的字幕文字、笔记文字、视频截图或音频分段发送到你填写的 OpenAI 兼容接口。
- **页面访问**：扩展需要读取网页中的 `<video>` 元素以提供播放控制和截图；不会收集浏览历史，不会上传页面内容到帧记服务器。

## 我们不做什么

- 不收集个人身份信息；
- 不向帧记或第三方出售、共享数据；
- 不在后台自动上传视频或笔记；
- 不接入百度账号，不会自动保存到百度网盘。

## 第三方 AI 服务

你配置的 AI 服务商可能会按照其隐私政策处理发送过去的文字或截图。请自行选择可信服务，并避免在公共设备上长期保存 API Key。

## 数据删除

- 在「笔记库」中删除单篇笔记；
- 在「设置 → 数据 → 清空所有笔记」删除全部本地数据；
- 卸载扩展会由浏览器清除扩展的本地存储。

## 联系方式

本扩展为本地开源项目，不提供云端账户服务。使用问题请通过项目仓库反馈。
