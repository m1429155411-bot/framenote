## 安装

1. Chrome/Edge 打开 `chrome://extensions` 或 `edge://extensions`；
2. 开启「开发者模式」；
3. 「加载已解压的扩展程序」，选择本文件夹；
4. 打开视频页面，首次点工具栏「帧记」图标；点击前不会注入任何界面。打开后页面右下角才有悬浮按钮，可按住拖动；面板可拖标题栏移动、拖右下角调整宽高。

## 使用

- **截图**：截取当前画面并插入图文笔记，自动带时间戳。
- **时间戳**：把当前播放位置插入光标处；大纲节点也可单独绑定。
- **识字**：本地 Tesseract OCR（离线）识别当前画面中英文；结果可编辑后插入。
- **听写**：独立的语音转文字工具，录制一段视频声音，先编辑带时间戳结果，再追加到文稿或插入图文。
- **AI 笔记**：按当前模板（图文/大纲/文稿）生成带时间戳的笔记；无字幕时会抽样画面 OCR，进度只显示在面板内。
- **自动识别音频**：文稿页打开「自动识别」，边看边分段转写；停止/视频结束后自动生成总结。需配置语音转写模型。
- **速览/练习/导图/助手**：生成摘要分章、单选题带解析、可下载思维导图、结合视频上下文问答。
- **导出**：Markdown、单文件 HTML、JSON、SRT、分享长图、打印/PDF。
- **设置**：填入任意 OpenAI 兼容接口；文本、视觉、语音模型可分开配置。API Key 只保存在本机。

## 隐私

无账号、无追踪、无自有服务器。笔记与截图保存在 `chrome.storage.local`；只有主动触发 AI 时才向你配置的接口发送必要内容。
